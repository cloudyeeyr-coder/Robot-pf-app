## 1. 비즈니스 핵심 소개

### Business Title
**로봇 SI 안심 보증 매칭 플랫폼** — 중소·중견기업 전용 로봇 자동화 시공사(SI) 신뢰 매칭 서비스

### Target Problem
국내 중소 제조업체(SME)가 로봇 자동화 도입 시 겪는 **두 가지 구조적 공포**:

1. **도입 전:** 수십 개 SI 업체 중 실력·재무 상태를 객관적으로 검증할 도구가 없음 → 잘못된 업체 선택 리스크
2. **도입 후:** SI 업체 파산·잠적 시 AS 단절, 수천만 원짜리 장비가 고철로 방치 → 재도입 트라우마

> *"내 돈 3천만 원이 고철덩어리가 됐어"* — 조상필 (실제 인터뷰 발언)
> *"기안 올릴 때 이 업체가 부도나면 누가 책임지나 하는 압박감이 큽니다"* — 김도진

### Solution — Core Features (MVP Phase 1)

| # | 기능명 | 해결하는 Pain |
|:---:|:---|:---|
| F-01 | **에스크로 결제** (PG사 위임, Admin 수동) | 계약금 100% 보호, SI 파산 시 전액 환불 |
| F-02 | **로컬 AS망 + 24h 출동 보증서** | 고철 방치 트라우마 원천 차단 |
| F-03 | **SI 투명 평판 뷰어** | 납기율·성공률·재무등급·리뷰 통합 열람 |
| F-04 | **제조사 인증 뱃지** | 브랜드별 공식 기술 검증 시각화 |
| F-05 | **RaaS 비용 비교 계산기** | CAPEX 부담 → 월 구독 ROI 전환 비교 |

## 2. 고객 제공 핵심가치 (Value Proposition Sheet)

> **핵심 슬로건:** *"절대 실패할 수 없는 로봇 도입의 시작 — 안심 에스크로 결제와 제조사 인증 로컬 AS 핫라인이 결합된 중소/중견기업 전용 로봇 SI 안심 보증 매칭 플랫폼"*

### 차별적 가치 3축

| 축 | 가치 | 실현 수단 |
|:---:|:---|:---|
| **① 100% 무한 보증망** | "내 투자금은 절대 날아가지 않는다" | 에스크로 + 로컬 AS 출동 보증서 |
| **② 정보의 성역 파괴** | "이 업체가 진짜 잘 하는지 직접 확인할 수 있다" | 제조사 인증 뱃지 + 납기/성공/실패율 투명 공개 |
| **③ O2O 밀착 케어** | "온라인이 불안하면 사람을 보내준다" | 전국 산단 오프라인 휴먼 컨설턴트 파견 (Phase 2) |

### 수익 모델
- **수요자:** 안심 보증료 **5~10%** (핵심 캐시카우) + RaaS 금융 쉐어 1.5~2%
- **공급자:** 파트너십 멤버십 (실버/골드/다이아) + S/W 마켓 수수료 15%

## 3. Core Persona 3명 — JTBD + CJM

### Persona A · 조상필 (P9) — 극단 사용자 | AOS 4.00 / DOS 3.20

**프로필:** 5인 미만 영세 제조업 대표, SI 업체 파산 경험자, Importance 5.0 / Satisfaction 1.0

**JTBD:**
> *"내 장비가 고철로 방치되지 않도록, 확실하고 무한한 수리 보증을 얻어 안심하고 싶다"*
- **Desired Outcome:** 고장 접수 후 **24시간 내 로컬 엔지니어 100% 방문** 보장
- **Switch Trigger:** 10~15% 보험료를 더 내더라도 "무한 보증 뱃지" 발견 시 즉시 전환

**고객 여정 (CJM):**

| 단계 | 행동·감정 | 핵심 Pain | 플랫폼 기회 |
|:---:|:---|:---|:---|
| 문제 인식 | 고철 로봇 보며 재도입 고민 / **분노** | AS 부재 트라우마 | "절대 고철로 두지 않겠다" 슬로건 노출 |
| 탐색 | 이행 보증만 체크, 나머지 불신 / **냉소** | 업체 파산 원초적 공포 | 안심 에스크로 구조 전면 노출 |
| 의사결정 | AS 보증 기간·긴급 출동 심문 / **의심** | 콜센터 느린 대응 두려움 | 반경 50km 로컬 AS 전담 파트너 매칭 |
| 사용 | 가벼운 오류에도 패닉 / **분노** | 기초 에러 대처 역량 전무 | 24hr 원격 관제 + 출동 |
| 유지 | 즉시 출동 경험 시 감동 전환 / **충성** | — | 공단 바이럴 앰배서더로 전환 |

### Persona B · 김도진 (P1) — 핵심 사용자 | AOS 2.88 / DOS 2.52

**프로필:** 중견기업 생산기술 팀장, 경영진 기안 담당자, Importance 4.8 / Satisfaction 2.0

**JTBD:**
> *"SI 업체의 재무·기술 평판을 객관적 외부 지표로 증명 받아 기안을 한 번에 통과시키고 싶다"*

- **Switch Trigger:** 객관적 평점·레퍼런스 영상 DB·신뢰 등급 뱃지 확인 시

**고객 여정 (CJM):**

| 단계 | 행동·감정 | 핵심 Pain | 플랫폼 기회 |
|:---:|:---|:---|:---|
| 문제 인식 | 상층부 지시로 로봇 도입 검토 / **부담감** | 객관적 SI 역량 가늠 지표 없음 | 평판/재무 등급 뱃지 제공 |
| 탐색 | 지인 수소문·박람회 발품 / **피로감** | 과장 제안서 vs 실제 스펙 차이 | 실제 공정 구동 레퍼런스 영상 DB |
| 의사결정 | 견적·재무 비교 심사 / **불안함** | 의사결정 지연 (리스크 회피) | 투명 재무 연동 + 에스크로 |
| 사용 | 현장 SI 투입·셋업 모니터링 / **예민함** | 소통 단절·진척 미상 | 프로젝트 PM 대시보드 |
| 유지 | ROI 측정·경영진 보고 / **안도감** | 다음 공정 확장 재탐색 부담 | 성공 데이터 기반 확장 제안 자동화 |

| 유지 | 우수 SI 동반 스케일업 / **만족** | 오프라인 파이프라인 확장 한계 | 최우수 SI 대상 B2B 리드 무료 제공 |

## 5. CTA 전략 — 구체적 행동 유도

> **목표:** 랜딩 페이지 방문자를 세 가지 행동 중 하나로 즉시 전환

### CTA #1 — 사전 예약 (Primary CTA · 조상필 타겟)
```
[지금 사전 예약하기 — 무한 AS 보증 1호 파트너 선점]
→ 출시 전 에스크로 보증 서비스 우선 배정 + 보증료 20% 할인 쿠폰 제공
→ 입력: 회사명 / 담당자 연락처 / 도입 예정 로봇 유형
```

### CTA #2 — 알림 설정 (Secondary CTA · 김도진 타겟)
```
[내 업종 맞춤 검증 SI 업체 등록 알림받기]
→ 업종·지역·로봇 브랜드 선택 → 해당 조건 SI 업체 신규 등록 시 즉시 알림
→ 기안용 레퍼런스 리포트 자동 발송 (PDF 1-Click)
```

### CTA #3 — 대기 리스트 등록 (Nurturing CTA · 강혁진 / 관망층 타겟)
```
[파트너 인증 대기 리스트 등록]
→ SI 업체 / 로봇 제조사 / 도입 희망 기업 구분 선택
→ 정식 오픈 시 역할별 온보딩 가이드 + 얼리버드 혜택 우선 안내
```

**긴급성 장치:** "현재 대기 리스트 **[N]명** 등록 완료 — 선착순 100명 한정 에스크로 수수료 면제"
