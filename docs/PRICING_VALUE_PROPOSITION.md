# 💎 요금 플랜별 핵심 가치 — S.H.I.E.L.D. 로봇 매칭 플랫폼

> **문서 목적**: 수요자(Buyer) 3플랜 + 공급자(Seller) 3플랜에 따라 각 고객군이 얻는 핵심 가치, 제거되는 Pain, 활성화 S.H.I.E.L.D. 에이전트를 정리한 영업/기획 기준 문서.

---

## 🏭 수요자 (Buyer) — 중소/중견기업

---

### 🆓 Free — "정보의 민주화"
> **"더 이상 박람회 발품 팔지 마세요. 검색 하나로 업계 정보를 공평하게."**

| 항목 | 내용 |
|:---|:---|
| **핵심 가치** | 아날로그 인맥 의존 → 디지털 투명 정보로 전환 |
| **제거하는 Pain** | 카탈로그·영업멘트 기반의 불투명한 시장 |
| **고객이 얻는 것** | "내가 먼저 걸러볼 수 있다"는 **정보 주도권** |
| **활성 에이전트** | H - Hardware & Tech AI (업체 탐색 및 기술 필터) |
| **Lock-in 포인트** | 재무 전체 등급은 Care 플랜에서 → 자연스러운 업셀링 |

**제공 기능**
- SI 업체 검색·필터 (지역·업종·규모)
- 제조사 인증 뱃지 확인
- SI 파트너 평판·재무 뷰어 **일부** 열람

**타겟 상황**: 로봇 도입 검토 초기, 아직 예산 승인 전인 실무자

---

### 🛡️ Care — "리스크의 완전한 외부 전가"
> **"수억짜리 결정을 혼자 책임지지 마세요. 실패의 짐을 플랫폼이 대신 집니다."**

| 항목 | 내용 |
|:---|:---|
| **핵심 가치** | 도입 전·중·후 모든 금전적·운영적 리스크를 플랫폼이 전담 |
| **제거하는 Pain** | "SI 부도나면 내 목이 날아감" (김도진), "고철 방치" (조상필) |
| **고객이 얻는 것** | **경영진 결재판에 올릴 수 있는 외부 보증 장치** |
| **활성 에이전트** | E (에스크로) + L (로컬 AS) + D (분쟁 예측) |
| **수익 구조** | 계약 금액의 **5~10% 안심 보증료** |
| **지불 의향 검증** | JTBD 인터뷰 — 10~15% 추가 지불 의향 **100% 확인** |

**제공 기능 및 가치**

| 기능 | 고객 가치 |
|:---|:---|
| 안심 에스크로 결제 | "약속 이행 전까지 내 돈은 내 것" |
| 24시간 긴급 출동 보증 | "콜센터 핑퐁 없이 엔지니어가 무조건 온다" |
| 파트너 부도 시 대체 시공 | "SI가 망해도 시공은 반드시 완료된다" |
| 블록체인 AS 보증서 발급 | "위·변조 불가능한 공식 보증 증서" |
| O2O 현장 매니저 예약 | "온라인이 불안하면 담당자가 공장으로 온다" |

---

### 💰 Finance — "자본 효율의 극대화"
> **"목돈 없어도 로봇 도입 가능. CAPEX를 OPEX로, 부담을 기회로."**

| 항목 | 내용 |
|:---|:---|
| **핵심 가치** | CAPEX 장벽을 월 구독(OPEX)으로 허물어 도입 결정 가속화 |
| **제거하는 Pain** | SME 44.2%가 초기 비용 부담으로 도입 주저 |
| **고객이 얻는 것** | **"투자 여력 없이도 지금 당장 자동화 시작"** |
| **활성 에이전트** | I (Investment ROI) + E + L + D 전체 |
| **수익 구조** | RaaS 금융사 이자 스프레드 쉐어링 **1.5~2%** |

**제공 기능 및 가치**

| 기능 | 고객 가치 |
|:---|:---|
| OPEX 비용 계산기 | "월 ~100만 원이면 협동 로봇이 내 공장에서 일한다" |
| 캐피탈·리스 36개월 연계 | "목돈 없이 분할로, 현금 흐름 지키며 자동화" |
| RaaS 구독 전환 신청 | "소유가 아닌 구독으로, 설비가 아닌 성과에 투자" |

## 🔧 공급자 (Seller) — SI 업체 / 로봇 제조사

---

### 📌 Starter — "온라인 존재감의 시작"
> **"전시회 명함 없이도, 전국 수요기업이 내 업체를 찾아온다."**

| 항목 | 내용 |
|:---|:---|
| **핵심 가치** | 연 매출 10억 이하 영세 SI의 유일한 온라인 판로 |
| **제거하는 Pain** | 박람회·지인 소개에만 의존하는 파편화된 영업 |
| **고객이 얻는 것** | 플랫폼 위의 **디지털 명함** |

**제공 기능**: 기본 프로필 등록, 시공 레퍼런스 DB 최대 3건

---

### 🚀 Pro — "검증된 업체로 브랜딩, 리드를 먼저 받는다"
> **"제조사가 인증한 업체임을 플랫폼이 증명해주고, 좋은 고객을 먼저 배정해준다."**

| 항목 | 내용 |
|:---|:---|
| **핵심 가치** | 무보수 선행 컨설팅 낭비를 인바운드 리드로 대체 |
| **제거하는 Pain** | 무보수 가설계에 소모되는 인적 자원 낭비 |
| **고객이 얻는 것** | **"질 좋은 수요를 먼저, 영업 낭비 없이"** |

**제공 기능 및 가치**

| 기능 | 공급자 가치 |
|:---|:---|
| 제조사 인증 뱃지 노출 | "내 기술력이 제3자에 의해 공식 증명된다" |
| 메인 상단 노출 | "수요자가 검색하면 내가 먼저 보인다" |
| 3D VOD 무제한 업로드 | "현장 가기 전에 시공 역량을 영상으로 먼저 증명한다" |
| 인바운드 리드 우선 배분 | "무보수 영업 없이, 관심 있는 고객만 연결된다" |

---

### 💎 Business — "제조사 공식 생태계 편입, VIP 지위 획득"
> **"플랫폼의 파트너가 아닌, 제조사의 공식 대리인으로 격상된다."**

| 항목 | 내용 |
|:---|:---|
| **핵심 가치** | 단순 SI 업체 → **제조사 공인 VIP 파트너**로 브랜드 레벨업 |
| **제거하는 Pain** | 브랜드 인지도 없어 수주 경쟁에서 밀리는 구조 |
| **고객이 얻는 것** | **"제조사 공식 네트워크에 이름이 올라가는 독점적 지위"** |

**제공 기능 및 가치**

| 기능 | 공급자 가치 |
|:---|:---|
| 제조사 공식 파트너 등록 | "제조사 보증을 등에 업고 수주 협상력이 달라진다" |
| 인바운드 리드 **전용** 배분 | "우선이 아닌 전용 — 경쟁 없이 좋은 고객이 배정된다" |
| 전담 계정 매니저 1:1 배정 | "플랫폼이 내 외부 영업팀이 되어준다" |
